# CodeAlpha_PhishingAwareness

A phishing awareness training module, built as an interactive website and a PowerPoint deck.

## What it covers
- How to recognise phishing emails and fake websites
- Types of phishing: email, spear phishing, smishing, vishing, fake websites
- Social engineering tactics: urgency, fear, authority, greed, curiosity
- Real-world scam patterns (typical scenarios with fictional names and links)
- Best practices, and what to do if you already clicked
- An interactive "spot the 5 warning signs" email demo
- An 8-question quiz with explanations

## Files
- `index.html`: the website. Open it in any browser, no setup needed.
- `CodeAlpha_PhishingAwareness.pptx`: the presentation version.

## Run it
Download `index.html` and open it in a browser.
